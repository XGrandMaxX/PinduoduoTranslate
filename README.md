# Пиндуо Перевод — свой переводчик для iPhone

Прототип нативного приложения: захват видимого экрана → распознавание китайского
через Apple Vision → перевод на русский через Apple Translation → окно
«Картинка в картинке» с русским и исходным текстом.

**Статус: обе схемы успешно собраны Xcode 27.1 на облачных Mac.
[Подтверждённая сборка](https://github.com/XGrandMaxX/PinduoduoTranslate/actions/runs/40718889228).
Получены IPA для физических iPhone (arm64). Подпись Apple, установка
и проверка работы на телефоне ещё не выполнены.**

[Репозиторий GitLab](https://gitlab.com/XGrandMaxX/pinduoduoTranslate) ·
[Проверки GitLab](https://gitlab.com/XGrandMaxX/pinduoduoTranslate/-/pipelines) ·
[Репозиторий GitHub](https://github.com/XGrandMaxX/PinduoduoTranslate) ·
[Сборки Xcode на GitHub](https://github.com/XGrandMaxX/PinduoduoTranslate/actions)

## Что предусмотрено

Две схемы Xcode:

- `PinduoTranslate27`: только iOS 27+, без расширения и App Groups. Захват,
  распознавание и перевод выполняются в основном приложении; временные данные
  хранятся в его личном контейнере. Этот вариант предназначен для первого iPhone
  с iOS 27.0.1 и пробной установки через персональную подпись Apple.
- `PinduoTranslate`: iOS 26+ с расширением ReplayKit для второго телефона
  и с новым захватом для iOS 27. Использует App Groups и требует соответствующей
  возможности при подписи.

- iOS 26: системный ReplayKit Broadcast Picker и расширение захвата.
- iOS 27+: ScreenCaptureKit и системный выбор экрана в основном приложении.
- Первая загрузка китайского и русского языков с разрешения пользователя;
  дальнейший перевод использует системные модели на устройстве, без API-ключей.
- Область распознавания: верхняя половина, нижняя половина или весь экран.
- Захват обрабатывается не чаще одного кадра за 1,5 секунды; это не обещание
  такой же задержки перевода. Реальная скорость на iPhone 11 пока не измерена.
- В окне помещается до 6 строк с оригиналом; в приложении — до 16 строк.
  Окно не заменяет китайские надписи внутри Pinduoduo.
- Очередь OCR ограничена одним кадром. Кэш перевода ограничен 128 фразами.
  Результат устаревшего экрана отбрасывается, если за время перевода текст сменился.
- Приложение не обращается к серверам Pinduoduo и не управляет покупками.

## Чего пока нельзя обещать

Устойчивость PiP при переходе в другое приложение, фоновая работа системного
перевода, расход памяти Vision в расширении iOS 26 и скорость на iPhone 11
требуют проверки на устройстве. OCR, перевод и PiP нельзя полноценно подтвердить
одной сборкой для симулятора. В очень динамичной ленте результат может
отбрасываться до остановки прокрутки.

Точность 100% недостижима. Декоративный шрифт, маленькие надписи и обрезанный
контекст снижают точность. Значок `[?]` показывает низкую уверенность OCR,
а не измеренную вероятность правильного перевода. Самостоятельные числовые
надписи не переводятся. Цены, единицы измерения, комплектацию, размеры и условия
возврата нужно сверять с оригиналом.

## Можно ли без своего Mac

Да, облачный macOS runner собирает проект. В `.github/workflows/ios-build.yml`
подготовлена **проверка сборки без подписи**. Она не устанавливает приложение
на телефон и не загружает его в App Store или TestFlight.

1. Открыть GitHub-репозиторий проекта по ссылке выше.
2. Открыть Actions → Check iPhone build → Run workflow.
3. Дождаться успешной сборки. При ошибке исправить исходники по артефакту
   `xcode-build-log` и повторить сборку.
4. Для установки организовать подписание приложения **и** расширения с одной
   зарегистрированной App Group, затем собрать подписанный архив на облачном Mac.
5. Для двух собственных устройств можно использовать Ad Hoc с зарегистрированными
   UDID; другой вариант — TestFlight после загрузки и необходимой обработки Apple.

**Неподписанный `.app.zip` не устанавливается на iPhone.**

Для текущего объединённого проекта App Groups нужны основному приложению
и расширению iOS 26; штатная подпись этой возможности требует подходящего
членства Apple Developer Program. Цена программы у Apple — 99 USD в год,
с учётом региональных условий и возможных налогов. Бесплатный Personal Team
не следует считать рабочим способом подписи этого проекта.

Схема `PinduoTranslate27` не использует App Groups и отдельное расширение.
Для неё можно пробовать бесплатную персональную подпись через AltStore Classic
на Windows с обычным Apple Account. Совместимость установщика с конкретной iOS
и успешная установка ещё не проверены. Бесплатная подпись требует обновления
приложения через AltServer каждые 7 дней; одновременно разрешены до 3 таких
приложений, включая AltStore. Не нужно покупать подписку ради этой проверки.

### Файл для установки на первый iPhone с iOS 27

GitHub Actions сохраняет `PinduoTranslate27-UNSIGNED.ipa`. Это приложение для
физического iPhone, упакованное в IPA, **без подписи Apple**. Просто открыть файл
на телефоне недостаточно. Установщик должен сначала подписать его вашим
Apple Account; вводить пароль нужно локально в установщике, не в репозитории,
не в CI-переменных и не в чате.

Используйте [официальную инструкцию AltStore Classic для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows).
Она требует Apple-компоненты для Windows, USB-подключение, доверие к ПК,
вход Apple Account, подтверждение приложения разработчика и Developer Mode.
После установки AltStore импортировать IPA через My Apps → `+`.
Выдачу доверия, вход и подтверждения на телефоне выполняет владелец устройства.
Подробнее о сроке подписи: [AltStore Getting Started](https://faq.altstore.io/altstore-classic/your-altstore).

Сценарии проверки не покупают членство Apple, не создают сертификаты
и не публикуют приложение в магазинах.
macOS runner может расходовать лимит GitHub Actions; тариф нужно проверить
в своём аккаунте перед запуском.

### GitLab вместо GitHub

В корне подготовлен `.gitlab-ci.yml`: обычный Linux runner автоматически
проверяет настройки проекта; Mac runner выполняет сборку без подписи.
По умолчанию запускается только проверка настроек и поиск секретов на Linux.
Для iOS-сборки после подключения Mac runner создать pipeline с переменной
`RUN_IOS_BUILD=1`, затем вручную запустить задание `iphone-unsigned-build`.
Оно использует тег `saas-macos-medium-m1` и образ
`macos-27-xcode-27` (образ у GitLab пока имеет статус beta). Артефакты — журнал
и неподписанное приложение, которое нельзя установить на телефон.

Облачные macOS runners GitLab.com доступны на Premium/Ultimate и в подходящих
программах open source. На Free требуется отдельно подключённый Mac runner:
в конфигурации нужно заменить тег и убрать `image`, если используется shell
executor. Обычный Linux runner iOS-приложение не соберёт.
Mac-задание включается явно, чтобы загрузка файлов сама не расходовала Mac-минуты.
Подробности: [macOS runners GitLab](https://docs.gitlab.com/ci/runners/hosted_runners/macos/).

## Локальная сборка, если появится Mac

Нужны Xcode 27 с SDK iOS 27, XcodeGen и физическое устройство iOS 26+.
SDK 27 нужен для компиляции нового захвата; минимальная iOS приложения — 26.

```sh
brew install xcodegen
python3 scripts/check_project.py
cp Config/Local.example.xcconfig Config/Local.xcconfig
# Заполнить Team ID, уникальный BUNDLE_PREFIX и APP_GROUP_ID.
xcodegen generate
open PinduoTranslate.xcodeproj
```

Зарегистрировать два Bundle ID: `BUNDLE_PREFIX` и `BUNDLE_PREFIX.broadcast`.
Создать App Group `APP_GROUP_ID` и назначить обоим App ID. В Xcode выбрать
свою команду, проверить Signing & Capabilities у обоих targets и запустить
схему `PinduoTranslate` на физическом iPhone. `Local.xcconfig` исключён из Git.

## Первый запуск

1. В приложении нажать «Загрузить китайский и русский». Разрешить загрузку
   системных моделей и дождаться успешного тестового перевода.
2. Нажать «Открыть окно перевода». Если PiP ещё готовится, подождать и повторить.
3. В iOS 26 нажать системную кнопку захвата и подтвердить начало трансляции.
   В iOS 27 нажать «Выбрать экран для перевода» и выбрать **весь экран**.
4. Открыть Pinduoduo. По умолчанию распознаётся верхняя половина экрана:
   сдвинуть PiP вниз. После прокрутки остановиться и проверить перевод.
5. Для завершения использовать системный индикатор захвата → остановка.
   В iOS 27 также есть кнопка «Остановить захват» в приложении.

Пауза перевода или закрытие PiP **не останавливает захват**. Система продолжает
показывать индикатор, пока захват не завершён явно.

## Данные

Платёжные реквизиты, API-ключи и сертификаты не должны попадать в исходники,
коммиты или CI-логи. В CI добавлен шаблонный поиск вероятных ключей и номеров
карт; он выводит только тип находки и путь, без самих значений. Это дополнительная
проверка, которая не гарантирует обнаружение любого секрета. При необходимости
подписи её секреты передаются отдельно через защищённые настройки CI,
а не добавляются в YAML. Артефакты GitLab ограничены ролью Maintainer.

Проверить исходники: `python3 scripts/check_secrets.py`.
Проверить доступную историю Git: `python3 scripts/check_secrets.py --git-dir .git`.

Кадры существуют только в памяти. В личном контейнере приложения (iOS 27)
или защищённом контейнере App Group (вариант с iOS 26) временно
сохраняется один текущий результат OCR, не история и не изображение.
Он перезаписывается, а при штатном завершении заменяется маркером без текста.
При аварийном завершении последний результат может остаться до следующего
запуска приложения. Кэш перевода — только в памяти; при получении маркера
остановки он очищается. Приложение не содержит сетевого клиента, аналитики
или сторонних SDK; первоначальными загрузками моделей управляет iOS.

## Проверка на устройствах — ещё не выполнена

- Сначала на втором iPhone с iOS 26.6.2: загрузка языков, старт захвата,
  появление PiP, 10 минут просмотра Pinduoduo и переходы между карточками.
- Затем на первом с iOS 27.0.1: системный выбор всего экрана, продолжение
  захвата в фоне и явная остановка. Проверить отмену системного диалога.
- Обычный китайский текст, таблица размеров, текст на картинке, пустой экран.
- Быстрая прокрутка: не должен показываться старый перевод новой карточки.
- Пауза, закрытие PiP, остановка захвата, блокировка и разблокировка экрана.
- Проверить память расширения iOS 26; при завершении системой потребуется
  уменьшить разрешение кадра или перенести OCR из расширения.
- Проверить фоновые ограничения Translation. Если перевод при PiP перестаёт
  выполняться, текущая архитектура потребует изменения; готовность не заявляется.

# Пиндуо Перевод для iPhone

Версия 0.2 добавляет браузер: сайт открывается внутри приложения, китайский
текст заменяется русским, а прокрутка, ссылки и кнопки остаются элементами сайта.
Текст на картинках распознаётся отдельно и показывается компактными подписями.
Это веб-версия сайта; приложение не перехватывает интерфейс нативного Pinduoduo.

[GitHub](https://github.com/XGrandMaxX/PinduoduoTranslate) ·
[Сборки iPhone](https://github.com/XGrandMaxX/PinduoduoTranslate/actions) ·
[GitLab](https://gitlab.com/XGrandMaxX/pinduoduoTranslate)

## Состояние проверки

Предыдущая версия с захватом установлена и открывается на iPhone с iOS 27.
Для браузерной версии добавлена локальная китайская демонстрационная страница.
Проверки JavaScript проверяют замену текста, сохранение обработчиков кнопок,
динамические изменения сайта, область экрана и исключение полей ввода.
Сборка Xcode проверяет обе схемы. Работа Apple OCR/Translation на телефоне
требует отдельной проверки после установки обновления.

**Открытие каталога, вход и оформление заказа на сайте Pinduoduo не проверены.**
Сайт может требовать нативное приложение или ограничивать встроенные браузеры.
Машинный перевод и распознавание могут ошибаться; точность 100% не гарантируется.

## Использование браузера

1. Открыть вкладку «Браузер». Первый запуск открывает локальную тестовую страницу.
2. При необходимости нажать «Загрузить китайский и русский» и разрешить загрузку
   системных моделей. Дальнейший перевод выполняется на устройстве.
3. Проверить перевод тестовой страницы, кнопку добавления в корзину и появление
   нового товара. Прокрутить страницу и остановиться для обновления подписей.
4. Ввести HTTPS-ссылку на сайт/товар либо самостоятельно выбрать закладку Pinduoduo.
5. В настройках выбрать замену текста и/или подписи на картинках. Размер, цвет
   текста, цвет подложки и прозрачность относятся к подписям. Заменённый текст
   страницы сохраняет шрифт и оформление сайта.
6. «Выделить область на странице» позволяет обвести прямоугольник пальцем.
   Область закреплена относительно экрана браузера. «Весь экран» сбрасывает рамку.
7. Кнопка RU/中文 включает перевод или восстанавливает исходный текст страницы.

Подписи пропускают касания. Во время прокрутки и изменения страницы старые
подписи скрываются, затем распознаются заново. Обработка ограничена одной
задачей; интервал проверки примерно 1,1 секунды, OCR — не чаще 2 секунд.
Это интервалы запуска, а не обещание задержки: скорость зависит от устройства.
Не переводятся поля ввода, редактируемые блоки, содержимое iframe, canvas
и блоки с translate="no" через DOM. Картинки можно переводить через OCR.

Переход в стороннее приложение требует отдельного нажатия. В нём перевод
браузера не действует. Исходный режим захвата оставлен во вкладке «Захват экрана»;
для браузера не нужны трансляция экрана и плавающее видео.

## Сборка и установка

- `PinduoTranslate27`: iOS 27+, без расширения и App Groups. Сохраняет Bundle ID
  предыдущей версии, поэтому подходит для обновления через Sideloadly.
- `PinduoTranslate`: iOS 26+, с ReplayKit-расширением и App Groups для режима
  захвата. Браузер входит в обе схемы; подписание расширения требует поддержки
  соответствующих возможностей команды разработчика.

GitHub Actions собирает обе схемы на облачном Mac с Xcode 27.1. Артефакты
`unsigned-app-*` содержат `.ipa` и `.app.zip` без подписи Apple. Для первого
телефона использовать `PinduoTranslate27-UNSIGNED.ipa`, подписав и установив
его локально через [Sideloadly](https://sideloadly.io/). Установить поверх старой
версии, не удаляя её. Apple Account, пароль и коды вводит владелец только
в локальном окне установщика. Секреты не нужны репозиторию или GitHub Actions.

На Mac: установить Xcode 27 и XcodeGen, выполнить `xcodegen generate`, открыть
проект и выбрать нужную схему. Индивидуальные значения команды и идентификаторов
можно указать в `Config/Local.xcconfig` по образцу `Local.example.xcconfig`.
Этот файл исключён из Git. Для схемы с расширением настроить общую App Group.
GitLab выполняет проверки на Linux; Mac-задание запускается только явно
с `RUN_IOS_BUILD=1` при наличии подходящего runner.

## Данные

Перевод использует Apple Translation на устройстве. JavaScript работает
в отдельном WKContentWorld и меняет только текстовые узлы страницы. Поля
ввода не отправляются в перевод; их прямоугольники маскируются перед OCR.
Снимки собственной веб-страницы существуют только в памяти. Кэш перевода
ограничен 256 фразами, очищается при навигации и не сохраняется на диск.
Сохраняются только настройки области и оформления. Cookies и сессия входа
хранятся стандартным локальным хранилищем WebKit; сам сайт получает обычные
веб-запросы, включая введённые пользователем данные.

Режим захвата отдельно сохраняет один текущий результат OCR в личном
контейнере (iOS 27) или App Group (iOS 26), без истории и изображений.
При аварийном завершении результат может оставаться до следующего запуска.
Остановка захвата выполняется явно; закрытие PiP само по себе его не останавливает.

Приложение не содержит аналитики, ключей API или сервера перевода. Платёжные
реквизиты, пароли и сертификаты не добавляются в публичный репозиторий.
`python3 scripts/check_secrets.py` проверяет вероятные секреты без вывода их
значений. `--git-dir .git` проверяет доступную историю. Это дополнительная
проверка, которая не гарантирует обнаружение любого секрета.

## Проверки

```sh
python3 scripts/check_project.py
python3 scripts/check_secrets.py
npm install --prefix build/test-deps --no-audit --no-fund --ignore-scripts jsdom@26.1.0
NODE_PATH=build/test-deps/node_modules node --test tests/browser_translation.test.cjs
```

Ресурсы `BrowserResources` должны входить в обе app-схемы. Демонстрация
не обращается в сеть и не принимает платежи. Автотесты используют синтетическую
страницу и не подтверждают совместимость Pinduoduo или качество перевода Apple.
